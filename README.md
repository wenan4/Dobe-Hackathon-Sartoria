# Sartoria AI — 海派高定与团体职业服 AI 企划辅助 Agent

> **赛题方向**：上海服装集团 · 服装板块｜AI+消费（IP类情绪消费 · 新消费）  
> **核心亮点**：结构化定制资产知识库（支持企业风格包扩展） · 六维感性需求解构 · **车企选配式场景可视化舞台（实景切换 + 热点缩放 + Three.js PBR 3D 面料实验室 + 参数化版型图纸）** · 三平台 AI 视觉提示词包 · 全流程业务台账与合规边界护栏

---

## 快速启动

环境要求：Node.js `>= 18`（推荐 Node 22）

```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务器
npm run dev

# 3. 运行核心引擎自动化测试
npx vitest run

# 4. 生产构建验证
npm run build
```

> 默认开启 **零 Key 本地领域语义引擎**，无需配置任何外部密钥或联网即可 100% 稳定完整演示；如需现场演示任意自由文案的大模型深度解析，可点击页面右上角 **「本地离线引擎」** 配置任意 OpenAI 兼容 API（如 DeepSeek / OpenAI / Qwen）。

## 核心交付物清单

1. **可演示 Agent Web 原型**（100% 静态模拟数据，Apple × Porsche × Loro Piana 极简静奢交互）：
   - `需求拆解`：直接将自然语言需求转译为官方标准 **8 项专业定制参数**（品类 / 版型结构 / 领型 / 面料 / 色彩 / 装饰纹样 / 长度比例 / 松弛余量，精准识别短颈/肚腩/溜肩/抬手坐奏等体态工学诉求），并支持一键切换赛题 **6 维情绪雷达图**
   - `场景选配`：车企/Apple 式选配体验——左侧全屏画廊舞台支持 **实景场景切换（白棚 / 正式礼厅 / 户外舞台 / 艺术沙龙 / 外滩晚宴 / 金融峰会）+ 极简热点缩放 + Three.js 3D 面料实验室 + 实时参数化版型图纸**；右侧纯白选配栏采用 Apple 圆形色卡点选、极简列表与渐进式详情折叠
   - `方案与提示词`：可打印定制方案初稿（含 8 项专业清单与人工终审边界声明）+ Midjourney / Flux / 即梦中文三镜头标准化提示词包
   - `资产库`：版型、面料、工艺与历史案例结构化检索 + 企业风格包扩展切换 + CSV 清单导出
   - `业务台账`：全流程动作留痕、人工流转状态编辑及 CSV / JSON / 打印上报单导出
2. **6 套完整模拟业务案例（全面融合官方案例 1–4 + 团装与晚宴高定）**：
   - **官方案例一**：端庄低立领 H 型中式外套（短颈 ≤3cm · 腹部松量 · 醋酸薄提花锦）
   - **官方案例二**：梅花暗纹青果领优雅外套（窄领显脖细 · 预留内搭 · 梅花暗花与星光点缀）
   - **官方案例三**：户外舞台演出服两件套（米白宋锦短外套配亮粉滚边 + 亮粉大 A 摆及踝裙 · 抬手坐奏放量）
   - **官方案例四**：香云纱内敛简约外套（溜肩自然落肩 · 低立领 ≤3cm · 原生哑光香云纱）
   - **团装案例**：陆家嘴国际资管集团 60 人海派现代职业套装
   - **晚宴案例**：外滩老洋房慈善晚宴海派新中式晚礼服
3. **完整方案架构文档**：详见 [docs/Sartoria-AI-Solution-Architecture.md](./docs/Sartoria-AI-Solution-Architecture.md)（含独立章节 **《Agent 能力边界清单》**）。

## 黑客松 3–5 分钟现场路演演示脚本

1. **开场（30s · `01 需求解构`）**：
   - 点击 **模拟案例 01《外滩鎏金夜》**，展示如何将客户“老上海电影感、克制高级、不老气”的感性碎片语言，一键转化为六大专业定制维度、六维雷达图与情绪审美标签报告。
2. **高潮（90s · `02 场景选配工作室`）**：
   - 进入车企式大舞台：底部一键切换 **「外滩晚宴 ↔ 静安艺术沙龙 ↔ 庭院酒会」** 展示成衣在不同设定场景中的光影融合；
   - 右侧切换 **「墨黛金丝宋锦 ↔ 月白烟青织锦缎 ↔ 绯红香云纱丝绒」** 实现“车企换漆般”的实时换装对比；
   - 点击服装上的 **金色脉冲热点** 平滑推进镜头看海派琵琶盘扣与玉兰苏绣，再切至 **「工艺与 3D 面料」** 拖拽 Three.js 3D 垂感织物演示灯光色温联动，切至 **「版型图纸」** 展示参数化实时重绘。
3. **双场景与风控护栏（60s · 切换模拟案例 02）**：
   - 返回快速切至 **模拟案例 02《浦江新韵》** 团体职业服：在陆家嘴金融大厅与外滩涉外礼宾厅间切换，演示藏青/暖灰/松墨绿三色系团装比对；
   - 故意点选一件纯丝娇贵面料，触发底部红色 **可行性风险护栏预警**，直观体现垂直行业专业护栏。
4. **交付闭环与合规边界（60s · `03 方案与视觉包` → `05 业务台账`）**：
   - 一键生成《海派定制整体方案初稿》与 Midjourney / Flux / 即梦三套提示词包（支持复制与导出 Markdown）；
   - 进入 `05 业务台账` 展示全流程自动留痕时间线与 CSV 一键导出，并点开右上角 **「能力边界清单」** 强调“纯辅助草稿、零越界报价与下单、人工终审闭环”。
